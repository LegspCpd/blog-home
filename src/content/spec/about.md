## 我是谁

我是 **LegspCpd**，一个喜欢折腾服务器和网络的普通开发者。

这个博客是`legspcpd.top`，从搭建、部署到写东西全是我一个人在做，所以你会看到内容比较杂：
既有成体系的技术教程，也有随手记的碎念和日记。

## 我在做什么

- **写作** —— 把踩过的坑、复盘的过程写成能复现的教程，顺手也给未来的自己留个备份。
- **自部署** —— 维护若干自托管服务与 Macro / API 接口，能自己拿在手里的就不交给别人。
- **折腾** —— 前端构建、边缘部署与自动化工具链，喜欢把东西塞进更快更省的位置。

## 关注的方向

- **边缘加速与 CDN**：Cloudflare、EdgeOne 的优选与线路优化
- **域名与 DNS**：解析、CDN 回源、证书与访问链路
- **边缘部署**：Vercel / Cloudflare / EdgeOne Pages 上的静态站点与函数
- **自托管**：把自己的服务与数据放在自己的机器上

## 兴趣与日常

写代码以外，我大部分时间花在看小说、听歌和打游戏上，偶尔把这些随手记在博客里。
不追求日更，只在意写下来的东西以后自己还看得懂。
