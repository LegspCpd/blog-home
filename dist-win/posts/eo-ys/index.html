什么是优选？

腾讯云 EdgeOne 是腾讯推出的全球边缘加速平台，覆盖国内三大运营商以及海外众多节点。虽然 EdgeOne 官方分配的节点质量已经不错，但在部分地区、部分运营商网络下，默认分配的边缘节点访问速度仍然可能不尽如人意，甚至出现跨网绕路的情况。

优选，就是通过手动调整 DNS 解析和路由规则，让你的域名解析到国内访问速度更快的 EdgeOne 边缘节点（Anycast IP），从而进一步降低延迟、提升可用性。

从上面的对比图可以看到，优选过的网站响应速度有明显提升，出口 IP 也变多了。这能让你的网站可用性大大提高，并且加载速度显著变快。

要实现优选，我们需要做到两点：自己控制路由规则 和 自己控制 DNS 解析。通过 EdgeOne 的边缘函数（Edge Functions）或自定义路由，我们可以同时实现这两点，下面会详细说明。

优选原理

首先我们要知道 CDN 是如何通过不同域名给不同内容服务的。

我们可以将其抽象为 2 层：规则层和解析层。当我们在 EdgeOne 上正常添加一条开启了加速的解析时，EdgeOne 会为我们做两件事：

  1. 帮我们写一条 DNS 解析，指向 EdgeOne 的 Anycast 节点
  2. 在 EdgeOne 创建一条路由规则，将该域名流量接入边缘网络

如果你想要优选，实际上你是要手动更改这个 DNS 解析，使其指向一个更快的 EdgeOne 节点。

但是，一旦你将加速关掉（去掉 CNAME/解析），路由规则也可能跟着失效，再访问就会显示 DNS 直接指向源站 IP——这就没法用了。

而 边缘函数（Edge Functions） 和 自定义路由 的出现改变了这一切：

  • 你可以自己写一条边缘函数路由规则（规则层）
  • 你可以自己写一条 CNAME 解析到优选节点（解析层）

这就是为什么经由边缘函数或自定义路由的流量可以做优选的原因。

选择优选域名

优选的核心就是选择一个国内访问速度更快的 EdgeOne 节点 IP 或域名。

传统优选域名

常用的社区优选域名可以参考：

  • https://eo.legspcpd.furry.bz/（作者维护）
  • https://e.legspcpd.furry.bz/（多IP版）

这些优选域名通常是通过扫描 EdgeOne 官方 IP 段，找出国内各运营商延迟最低的 IP 整理而成。

提示：如果你有多个不同运营商的线路需求，多 IP 优选域名通常能提供更好的兼容性，因为不同运营商访问同一 Anycast IP 时可能命中不同的节点。

各类优选方案

使用 A/AAAA 记录指向指定 IP

打开你的 DNS 服务商（腾讯云 DNSPod、阿里云、Cloudflare 等），为你的域名新建一条 A 记录（或 AAAA 记录）。

  1. 找一个 EdgeOne 优选 IP（可以参考社区测速结果，或者自己用 ITDOG 测速）
  2. 新建 A 记录，记录值 填优选 IP
  3. 关闭 DNS 服务商自带的 CDN/代理（因为是直接解析到优选 IP）

然后我们打开 ITDOG 进行测速，验证解析是否生效、速度是否理想。

已经解析完毕，可以使用。

使用边缘函数路由（Edge Functions）

如果你有多个域名、多个源站需要同时优选，使用边缘函数会更灵活。

EdgeOne 的边缘函数与 Cloudflare Workers 类似，你可以编写一个简单的反代函数，根据请求的 Host 头将流量转发到对应的源站，同时让域名解析指向优选节点。

核心思路：

  1. 在 EdgeOne 控制台创建一个边缘函数，根据 Host 头映射目标源站
  2. 为你的域名创建一条边缘函数路由
  3. 将域名的 DNS 解析指向优选域名（CNAME 到优选节点）

这样规则层（边缘函数）和解析层（DNS）就完全由你自己控制了。

注意：边缘函数方案请务必测试好回源逻辑，确保源站响应正常后再切换正式流量。

多 IP 优选方案

单 IP 优选在某个运营商线路异常时可能影响访问。多 IP 方案通过在不同运营商线路、不同节点上做解析分流，提升整体可用性：

  • 使用支持线路解析的 DNS 服务商（如 DNSPod），针对电信、联通、移动分别解析到不同的优选 IP
  • 或者使用作者提供的多 IP 优选域名（e.legspcpd.furry.bz），由服务端自动做多节点负载

这种方式在运营商网络波动时依然能保持较好的访问体验。

配合 EdgeOne Pages / 静态托管

如果你使用的是 EdgeOne Pages 托管静态站点：

  1. 可以直接将绑定到 Pages 的子域名更改为线路分流解析
  2. 也可以将站点迁移到边缘函数方案，配合优选节点使用，效果更灵活

常见问题

Q：优选后我的源站会不会暴露？ A：不会。优选只是让边缘节点更快地接入，回源请求仍然由边缘节点发起，源站 IP 并不会直接暴露给访客。

Q：优选 IP 失效了怎么办？ A：建议定期使用 ITDOG 等工具测速，如果发现某条线路明显变慢，及时更换解析到的优选 IP。多 IP 方案能有效降低单点失效的影响。

Q：和 Cloudflare 优选有什么区别？ A：思路完全一致，只是平台不同。EdgeOne 在国内的节点覆盖和接入质量本身就不错，优选能进一步挖掘潜力，尤其适合对延迟敏感的用户。

Q：可以同时用多个优选方案吗？ A：可以。比如主域名用边缘函数方案，备用域名用 A 记录方案，相互冗余，可用性更高。

总结

EdgeOne 优选的核心就是自己控制 DNS 解析 + 自己控制路由规则：

  1. 先选择一个国内访问快的优选节点
  2. 通过 A/AAAA 记录、边缘函数或线路解析，将域名解析到优选节点
  3. 定期测速、维护，保证长期稳定
